# DZH3 vendor DTB inspection

Read-only static inspection of the supplied vendor_boot.img. All 22 DTBs parsed successfully and consumed the entire 8,586,579-byte concatenation without gaps. Individual trees are in `dtbs/vendor-00.dtb` through `vendor-21.dtb`.

## Interpretation limits

Every tree has `/memory/reg = <0 0 0 0>` with two address and two size cells. This is a static placeholder; actual memory bank addresses and sizes must be filled at boot. These files therefore do not establish a live memory map or a Linux image load address. The collection contains multiple platform variants, and the runtime-selected base DTB and overlays have not been established.

All 22 trees declare `/reserved-memory/gunyah_hyp_region@80000000` as a `no-map` region beginning at `0x80000000` with length `0x00e00000` (14 MiB). The exclusive end is `0x80e00000`.

## Pineapple v2 declarations

Index 5 identifies `qcom,pineapple`, MSM ID `0x22d`, revision `0x20000`. The selection of this base tree on the supplied phone remains a runtime assumption. Its static `reserved-memory/reg` ranges and all parsed properties are preserved in `vendor-dtb-metadata.json` output generated by `vendor_dtb_parser.py`.

## Relevant static boot arguments

Pineapple-family `/chosen/bootargs` include `kpti=0`, `kasan=off`, `disable_dma32=on`, `transparent_hugepage=never`, `fw_devlink.strict=1`, and vendor firmware paths. These are declarations in the image; the bootloader can append or replace arguments.

## Embedded firmware identifier

The vendor_boot image contains `S928USQS6DZH3` in numerous vendor module build strings and in its Samsung signing trailer at file offset `0x1707020`; `SM-S928U` appears at `0x1707050`. The attached image therefore has embedded identifiers matching the requested firmware. Its signature chain was not cryptographically verified.
